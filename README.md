# Lumi – Landing Page

Landing page de **Lumi**, la app que une el seguimiento del ciclo menstrual con la agenda diaria.
Startup **6Bits** · UPC · IHC y Tecnologías Móviles (1ASI0385).

## Prototipos

| Carpeta | Entrega | Estado |
|---|---|---|
| [`prototipo-1/`](prototipo-1/) | Primera entrega | Estructura completa, estilos base y responsive |

Para verlo, abre `prototipo-1/index.html` en el navegador.

## Estructura del prototipo 1

```
prototipo-1/
├── index.html               ← todas las secciones, marcadas con comentarios "PARTE X"
├── css/
│   ├── base.css             ← colores, tipografía, botones y tarjetas (compartido)
│   └── secciones/           ← un archivo CSS por sección
├── js/
│   ├── menu.js              ← menú desplegable en celular
│   └── faq.js               ← preguntas frecuentes desplegables
└── assets/img/              ← logo e imágenes
```

Diseño de referencia: Figma `LUMI-grupo1-2026` (Style Guide y Landing Page Desktop 1440 / Mobile 375).
